<h1>BrickBreaker</h1>

Sebuah game sederhana penghancuran balok menggunakan bola, mirip seperti <i>Brick Breaker</i> orisinal milik Ali Asaria.

Game ini memiliki fitur sebagai berikut:
- Kecepatan bola yang meningkat seiring level (<i>reset</i> setiap 5 level)
- Sistem <i>skin</i> untuk balok, bola, dan padel yang menggunakan poin sebagai pembayaran
- Sistem audio rudimenter menggunakan <i>Envelope Generator</i> (sarung suara)
